## 🌐 Publishing to GitHub (10 Minutes)

### For the Portfolio Website:

1. **Create Repository:**
   - Go to [github.com/new](https://github.com/new)
   - Name: `yourusername.github.io` (use YOUR username!)
   - Make it Public
   - DON'T add README (you already have files)
   - Click "Create repository"

2. **Upload Files:**
   
   **Option A - Using Git (if installed):**
   ```bash
   cd "d:\My Portfolio"
   git init
   git add .
   git commit -m "Initial commit - My awesome portfolio"
   git branch -M main
   git remote add origin https://github.com/yourusername/yourusername.github.io.git
   git push -u origin main
   ```

   **Option B - Using GitHub Website (easier):**
   - On your new repository page, click "uploading an existing file"
   - Drag ALL files (index.html, style.css, script.js, images folder)
   - Click "Commit changes"

3. **View Your Live Site:**
   - Wait 2-3 minutes
   - Visit: `https://yourusername.github.io`
   - Your portfolio is LIVE! 🎊

### For the GitHub Profile README:

1. **Create Special Repo:**
   - Go to [github.com/new](https://github.com/new)
   - Name: Your EXACT username (e.g., `BrimaFuller`)
   - Make it Public
   - Check "Add a README file"
   - Click "Create repository"

2. **Add Content:**
   - Click the ✏️ edit button on the README
   - Delete everything
   - Open the `README.md` file from your portfolio
   - Copy ALL content
   - Paste into GitHub
   - Replace `yourusername` with your username
   - Click "Commit changes"

3. **See Your Profile:**
   - Go to `https://github.com/yourusername`
   - Your profile README is now showing! 🌟

## 🆘 Having Issues?

### Profile Photo Not Showing?
- Make sure file is named exactly: `profile.jpg` (lowercase)
- Make sure it's in the `images` folder
- Try refreshing your browser (Ctrl + F5)

### Website Looks Broken?
- Make sure all 3 files are in the same folder: index.html, style.css, script.js
- Make sure images folder is in the same location
- Try clearing browser cache

### GitHub Pages Not Working?
- Wait 5-10 minutes after first push
- Check repository name is exactly: `yourusername.github.io`
- Make sure repository is Public, not Private
